#### 8. エナジーチャージS たくわえる (Charge Strength S (Stockpile))
| 項目 | 内容 |
|------|------|
| 最大レベル | 7 |
| 日本語名 | たくわえる（エナジーチャージS） |
| 効果 | 発動時に「たくわえる」か「はきだす」がランダムに発生する。たくわえる：チャージを1つ蓄積する（最大10まで）はきだす：蓄積したチャージをすべて消費し、個数に応じたエナジーを獲得する |

**EP計算（TeamTimeline）**: `skillEP = totalDirectSkillEP`

**確率と仕様**
- **発動率**: 「たくわえる」が約73%、「はきだす」が約27%と言われています。
- **エナジー**: 「はきだす」発動時のエナジー量は、蓄積回数が多いほど指数関数的に増加します。
- **リセット**: チームから外すと蓄積回数はリセットされます。
- **対象**: フワンテ、フワライド

## タイムラインでの表記について
一度にスキルが複数回発動したとき、基本的には複数回分の獲得物を加算してまとめて表示する。
例:エナジーチャージ(400EP)が２回発動した場合　→ ❗❗+800EP
ただし、対象のポケモンが都度変わるスキルや、効果内容が大きく変わる、ゆびをふるなどのスキルは、
複数行にわたって表示する。
例：
❗ピカチュウ ❇️+12
❗カイリュー ❇️+12



## 利用上の注意

### コード参照

このドキュメントのデータは以下のファイルから直接抽出されたものをベースにしています：

- **メインスキル定義**: `pokesleep-tool/src/util/MainSkill.ts`
  - `getSkillValue()` - レベル別効果値
  - `getSkillSubValue()` - 副次効果値
  - `getSkillRandomRange()` - ランダムスキルの範囲
  - `getLunarBlessingBerryCount()` - みかづきのいのりのきのみテーブル


- **スキルEP集計（日次）**: `src/extensions/apps/TeamTimeline/simulation/EnergyPointCalculator.ts`
  - `calculateDailySummary()` - `skillEP` の分岐集計
- **スキル分類・効果処理**: `src/extensions/apps/TeamTimeline/simulation/SkillEffectProcessor.ts`
  - `isNonEPSkill()` / `isDirectEPSkill()` / `isProxySkill()`
- **時間帯結果のdirectEP生成**: `src/extensions/apps/TeamTimeline/simulation/TimelineSimulator.ts`
  - `directSkillEP` を `TimeSlotResult` へ格納
- **スキル食材の別集計と合算**: `src/extensions/apps/TeamTimeline/simulation/EnergyPointCalculator.ts`
  - `skillIngredients` を別集計しつつ、`ingredientEP` と食材合計には合算して反映

- **日本語翻訳**: `pokesleep-tool/src/i18n/ja.json`
  - `skills` キー以下にメインスキル名

### データ更新

ゲームのバランス調整により、スキルの数値が変更される場合があります。最新の情報は必ず上記ファイルで確認してください。
